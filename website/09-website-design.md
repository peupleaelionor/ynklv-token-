# PART 9 — WEBSITE DESIGN

## YNKLV.xyz — Premium Landing Page Architecture

---

## 9.1 — DESIGN BRIEF

The YNKLV website is not a crypto project page. It is the digital headquarters of a cultural movement.

It must achieve:
1. **Immediate emotional resonance** — in the first 3 seconds, a visitor must feel that this is different
2. **Narrative clarity** — a visitor who knows nothing about crypto must understand what YNKLV is for
3. **Cultural authenticity** — an African creator must feel seen, not tokenized
4. **Technical credibility** — a Web3 developer must see a serious, well-thought project
5. **Conversion** — the right visitors must want to join, create, or build

**Single primary CTA throughout the site:** "Join the Ecosystem"

**Color:** Dark. The image is rich and slightly underexposed. Gold text glows against the darkness.

## 9.4 — MOBILE DESIGN NOTES

The website must be built mobile-first. For the African user base, mobile is the primary device.

**Mobile-specific treatments:**
- Hero section: Portrait orientation, text centered, video replaced with static image on 3G
- Navigation: Minimal hamburger menu — max 6 items
- Font scale: Reduced but still large — readability over hierarchy
- CTAs: Full-width buttons — generous touch targets
- Sections: Full-width single column — no horizontal scroll traps
- Images: WebP format, lazy-loaded, aggressive compression

**Performance target on mobile:**
- Under 3 seconds to First Contentful Paint on 3G
- Under 500KB initial page load
- Functional without JavaScript (critical information accessible)

---

## 9.5 — COPY PRINCIPLES

**Writing style:**
- Short sentences.
- Never exceed 25 words in a sentence.
- Active voice always.
- No jargon (blockchain, DeFi, Web3 — never in headline copy).
- No metaphors about "revolutionizing" or "disrupting."
- Direct address: "you," not "users."

**Language versions:**
- French (primary for Francophone Africa and diaspora)
- English (primary for Anglophone Africa and global)
- Auto-detect browser language, easy toggle

**Tone benchmark:**
Read every piece of copy and ask: "Could Apple write this?" Not because we copy Apple, but because the standard of restraint, clarity, and confidence should be comparable.

---

## 9.6 — TECHNICAL IMPLEMENTATION

**Stack:**
- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion (scroll-triggered animations)
- Vercel (deployment, edge functions for geo-detect)
- Sanity CMS (for blog, creator spotlights, roadmap updates — marketers can update without engineers)
- Plausible Analytics (privacy-first)

**SEO:**
- Proper semantic HTML throughout
- Open Graph images for every page (custom, on-brand)
- Structured data (Organization, WebSite schemas)
- Multi-language hreflang tags
- Sitemap.xml + robots.txt

**Accessibility:**
- WCAG 2.1 AA minimum
- Screen reader tested
- Keyboard navigation complete
- Sufficient color contrast (especially gold on dark)
- Alt text for all images
